# Offline Beats

A personal music player for audio files you choose on your device. It is a static website that can be installed on Android through Chrome and used offline after its first online visit.

## Features
- Home, Library, Playlists, and Liked Songs tabs
- Import multiple local audio files
- Music file storage in browser IndexedDB on this device
- Search, like/unlike, and playlists
- Play/pause, previous/next, seek, 10-second skip, shuffle, repeat, playback speed
- Offline app shell using a service worker

## Publish with GitHub Pages (Android-friendly)
1. Download and unzip this project.
2. On GitHub, create a **new public repository** named `offline-beats` (or another name).
3. Open the repository and tap **Add file → Upload files**.
4. Upload the *contents* of this folder, not the outer folder itself. `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icon.svg`, and `README.md` should appear directly on the repository's main Code page.
5. Tap **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**. Select branch **main** and folder **/(root)**, then tap **Save**.
8. Wait a minute or two. Open the website address shown in Settings → Pages using **Chrome**, not an in-app browser.
9. Keep the site open online once so the app shell can cache. In Chrome's menu (⋮), choose **Add to Home screen** or **Install app** if offered.
10. Open Offline Beats from your home screen. Tap **Add songs** and select audio files from your phone.

## Important notes
- Imported songs are stored in the browser's private storage on that device. They do not upload to GitHub or any server.
- If you clear Chrome's site data, the imported library may be erased. Keep original music files elsewhere too.
- A PWA needs a secure site such as GitHub Pages (HTTPS) to install and cache offline. Opening `index.html` directly as a file is not the intended installation method.
- The browser needs to support the selected audio format. MP3 is usually the safest choice.
- GitHub Pages publishing can take a few minutes after the first setup.
